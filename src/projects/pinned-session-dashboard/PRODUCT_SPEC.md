# Pinned Session Dashboard 상세 기획서

## 1. 제품 정의

Dashboard는 반복해서 사용하는 채팅 세션을 최대 4개까지 한 화면에 고정하고, 각 세션의 맥락을 유지한 채 바로 입력하는 작업 화면이다. 패널은 템플릿이나 복사본이 아니라 원래 채팅 세션과 연결된 실시간 작업 창이다.

핵심 원칙은 다음과 같다.

1. Dashboard와 일반 채팅 화면은 같은 세션 상태를 공유한다.
2. 일반 새 채팅과 Dashboard 패널 생성을 사용자가 누른 위치에 따라 명확히 구분한다.
3. 고정, 해제, 생성 중, 새 결과, 확인 상태는 즉시 구분되어야 한다.
4. 화면에 보이는 모든 조작 요소는 실제로 작동해야 한다.

## 2. 정보 구조

동작 프로토타입은 프로젝트 문서 안에 삽입하지 않고 `#/apps/pinned-session-dashboard` 단독 페이지에서 실행한다. 프로젝트 문서의 `프로토타입` 탭은 이 페이지로 이동하는 링크 역할만 한다.

사이드바에는 Dashboard, 채팅 검색, 전체 세션 목록, 새 채팅 버튼, 사이드바 닫기 버튼을 둔다. 세션 목록의 핀 아이콘은 Dashboard 고정 여부를 나타내며 패널 상태와 항상 일치한다. 사이드바를 닫으면 본문이 창 전체 너비를 사용하고 좌측 상단 버튼으로 다시 열 수 있다.

Dashboard 본문은 다음 요소를 가진다.

- 화면 제목과 현재 고정 수 `n / 4`
- 최대 4개의 세션 패널
- 자리가 남아 있을 때 표시되는 하나의 `새 채팅 시작` 패널
- 처리 결과를 알리는 하단 토스트

패널은 제목, 작업지시 요약, 최근 사용자 요청, 최근 답변, 입력창, 전체 화면 열기, 고정 해제, 재정렬 그립을 가진다.

## 3. 패널 배치

Dashboard는 고정 세션과 새 채팅 패널을 합쳐 다음과 같이 배치한다.

- 0개 고정: 새 채팅 패널 하나를 전체 영역에 표시한다.
- 1개 고정: 기존 패널과 새 채팅 패널을 한 줄에 표시한다.
- 2개 고정: 첫 줄에 기존 패널 2개, 둘째 줄 전체에 새 채팅 패널을 표시한다.
- 3개 고정: 2x2 배치의 마지막 칸에 새 채팅 패널을 표시한다.
- 4개 고정: 2x2 배치로 세션 패널만 표시한다.

사용자는 패널 사이 경계를 드래그해 각 행과 열의 비율을 조절할 수 있다. 그립을 드래그해 패널 순서를 바꿀 수 있다.
한 행이 세션 패널과 새 채팅 패널로 구성된 경우에도 두 칸의 좌우 비율을 조절할 수 있다. 이는 고정 세션이 1개인 한 줄 배치와 3개인 2x2 배치의 아래 행에 동일하게 적용한다.

## 4. 새 채팅

사이드바 상단의 새 채팅 버튼은 일반 채팅을 전체 화면으로 연다. 이 채팅은 자동으로 Dashboard에 고정하지 않는다.

Dashboard의 빈 패널을 누르면 다음 동작이 한 번에 일어난다.

1. `새 채팅` 세션을 만든다.
2. Dashboard의 빈 자리에 고정한다.
3. Dashboard 화면을 유지한다.
4. 새 패널의 입력창에 포커스를 둔다.
5. 첫 요청을 전송하면 요청 내용을 바탕으로 제목을 갱신한다.

Dashboard가 가득 찬 상태에서는 세션을 추가하지 않고 `대시보드가 가득 찼습니다` 토스트만 표시한다.
일반 채팅 화면에서 이 제한에 도달한 경우 토스트에 `이동` 액션을 제공해 현재 Dashboard 구성을 바로 확인할 수 있다.

## 5. 고정과 해제

일반 채팅 화면이나 사이드바에서 핀을 누르면 세션을 Dashboard에 고정한다. 다른 화면에서 고정한 경우 토스트에 `이동` 액션을 제공해 Dashboard로 갈 수 있다.

고정 직후에는 핀 아이콘이 채워지고, 사이드바의 Dashboard 개수 배지가 갱신되며, 새로 추가된 패널만 짧게 강조된다. 세 피드백은 상태 변화를 설명하기 위한 일회성 반응이며 반복 애니메이션은 사용하지 않는다.

Dashboard 패널이나 사이드바에서 핀을 해제하면 패널만 Dashboard에서 사라지고 채팅 기록은 유지된다. 토스트의 `되돌리기`를 누르면 세션을 원래 위치에 다시 고정한다.

## 6. 입력과 결과 상태

Dashboard 패널과 일반 채팅 화면은 같은 입력값과 결과를 공유한다. `Enter`는 전송하고 `Shift+Enter`는 줄바꿈한다.
각 어시스턴트 답변 아래에는 해당 답변 전체를 클립보드에 복사하는 버튼을 둔다. 복사에 성공하면 버튼 아이콘이 잠시 체크 상태로 바뀐다.

- 대기: 입력을 기다리는 기본 상태
- 생성 중: 진행 바와 `생성 중` 표시, 중복 전송 방지
- 새 결과: Dashboard 패널 테두리, 상태 배지, 사이드바 점으로 표시
- 확인함: 결과 패널을 클릭하거나 일반 채팅으로 열면 새 결과 표시 제거

Dashboard에서 시작한 작업을 일반 채팅으로 열거나, 일반 채팅에서 시작한 작업을 Dashboard에서 이어서 입력해도 같은 세션이 갱신되어야 한다.

## 7. 검색과 전체 화면

사이드바 검색은 세션 제목과 작업지시 요약을 실시간으로 필터링한다. 결과가 없으면 빈 결과 문구를 표시한다.

패널의 전체 화면 열기 버튼은 해당 세션의 일반 채팅 화면으로 이동한다. 일반 채팅에서 전송한 결과도 Dashboard 패널에 반영된다.

## 8. 피드백과 접근성

- 모든 아이콘 버튼은 이름과 툴팁을 가진다.
- 키보드 포커스가 보이며 입력과 주요 버튼을 키보드로 조작할 수 있다.
- 토스트는 스크린 리더에 상태 변경을 알리고 `Escape`로 닫을 수 있다.
- 실행 가능한 버튼과 비활성 버튼의 시각 상태를 구분한다.
- 호버에만 의존하지 않고 패널의 주요 도구를 기본 상태에서도 확인할 수 있다.
- 창 하단 경계를 포인터로 드래그하거나 키보드 방향키로 창 높이를 조절할 수 있다.

## 9. 완료 기준

- Dashboard와 사이드바의 고정 상태가 항상 일치한다.
- 사이드바 새 채팅은 일반 채팅으로 열리고 Dashboard 빈 패널의 새 채팅만 자동 고정된다.
- Dashboard 새 채팅 생성 즉시 패널과 세션 목록에 추가되고 입력 포커스가 이동한다.
- 4개 제한을 지키며 초과 시 기존 패널을 임의로 교체하지 않는다.
- 고정 해제와 되돌리기가 원래 패널 순서를 보존한다.
- 패널과 일반 채팅의 입력, 생성 상태, 결과가 동기화된다.
- 검색, 전송, 결과 확인, 전체 화면 열기, 재정렬, 패널 및 창 크기 조절, 사이드바 접기가 실제로 작동한다.
- 데스크톱 기준에서 텍스트와 조작 요소가 겹치지 않는다.
- `pnpm build`가 통과한다.
