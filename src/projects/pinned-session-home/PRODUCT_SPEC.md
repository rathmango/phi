# Pinned Session Home 상세 기획서

## 1. 문제와 제품 원칙

사용자는 LLM 채팅 앱에서 반복해서 쓰는 작업지시를 다시 적용하고 싶지만, 해당 작업지시가 여러 채팅 세션에 흩어져 있어 매번 과거 세션을 찾아야 한다. 이 기능의 목적은 새 작업 모드를 만드는 것이 아니라, 사용자가 이미 쓰고 있던 채팅 세션을 Home에 꺼내두고 바로 입력하게 만드는 것이다.

제품 원칙은 세 가지다.

1. Home은 채팅 세션의 복사본이 아니라 원래 세션을 보여주는 작업대다.
2. Home에 고정한 세션은 한 화면에서 바로 찾고 바로 입력할 수 있어야 한다.
3. 고정, 제거, 작업 완료, 미확인 상태는 사용자가 즉시 이해할 수 있어야 한다.

## 2. Home의 정의

Home은 반복해서 다시 쓰는 채팅 세션을 최대 4개까지 고정해두는 작업 화면이다. Home에 있는 패널은 별도 템플릿이나 새 대화가 아니라 기존 채팅 세션의 라이브 패널이다.

Home에 고정된 세션은 다음 조건을 가진다.

- 각 패널은 세션 제목, 작업지시 요약, 최근 대화, 입력창, 상태 표시를 가진다.
- 패널에서 입력한 내용은 해당 세션의 맥락과 작업지시를 기준으로 실행된다.
- Home에서 제거해도 원래 채팅 세션은 삭제되지 않는다.
- Home에는 최대 4개 세션만 고정할 수 있다.
- 5번째 세션을 고정하려 하면 기존 고정 세션 중 하나를 교체해야 한다.

## 3. 위치와 이름

사이드바에는 `Home` 항목을 둔다. Home 항목 아래에는 일반 채팅 세션 목록이 이어진다. 별도의 `프로젝트`, `라이브러리`, `GPT` 같은 카테고리는 이 프로토타입 범위에서 제외한다.

세션 목록의 핀 아이콘은 해당 세션이 Home에 올라와 있는지 보여준다. Home 화면의 패널과 세션 목록의 핀 상태는 항상 일치해야 한다.

## 4. 고정과 제거 인터랙션

### 4.1 Home에 고정

사용자가 채팅 세션의 핀 버튼을 누르면 시스템은 해당 세션을 Home에 고정한다.

고정 시 일어나는 변화는 다음과 같다.

1. 세션 목록의 핀 아이콘이 채워진 상태로 바뀐다.
2. Home 화면에 해당 세션 패널이 추가된다.
3. 토스트가 나타난다. 예: `비즈니스 영어 번역이 Home에 고정되었습니다.`
4. 토스트에는 `실행 취소` 액션이 있다.

### 4.2 Home에서 제거

사용자가 Home 패널의 핀 아이콘을 누르거나 세션 목록에서 핀을 해제하면 시스템은 해당 세션을 Home에서 제거한다.

제거 시 일어나는 변화는 다음과 같다.

1. 세션 목록의 핀 아이콘이 비어 있는 상태로 바뀐다.
2. Home 화면에서 해당 패널이 사라진다.
3. 토스트가 나타난다. 예: `Home에서 제거되었습니다. 채팅 기록은 유지됩니다.`
4. 토스트에는 `실행 취소` 액션이 있다.

### 4.3 5번째 세션 고정

Home에 이미 4개가 고정되어 있을 때 다른 세션을 고정하려 하면 곧바로 추가하지 않는다. 시스템은 교체 대상을 선택하는 화면을 보여준다.

사용자가 교체할 패널을 선택하면 다음이 일어난다.

1. 선택한 기존 세션은 Home에서 제거된다.
2. 새 세션이 Home에 고정된다.
3. 세션 목록의 핀 상태가 동시에 갱신된다.
4. 토스트가 나타난다. 예: `랜딩페이지 리뷰 배치 연구가 Home에 고정되었습니다.`

## 5. 패널 위계와 크기

Home의 기본 배치는 2x2 4분할이다. 다만 모든 세션의 중요도가 항상 같지는 않기 때문에 패널은 세 가지 크기 상태를 가진다.

- 기본: 2x2 그리드 안의 표준 패널
- 크게 보기: 현재 가장 중요한 세션. 가로 2칸을 차지한다.
- 작게 접기: 계속 두고 싶지만 당장은 덜 중요한 세션. 내용 영역을 줄이고 핵심 상태와 입력창만 유지한다.

사용자는 패널 상단의 크기 버튼으로 기본, 크게 보기, 작게 접기 상태를 전환할 수 있다. 크게 보기와 작게 접기는 Home에서의 시각적 위계만 바꾸며, 세션의 작업지시나 대화 내용은 바꾸지 않는다.

## 6. 작업 상태

Home 패널은 작업 진행 상태를 가진다.

- 대기: 입력을 기다리는 기본 상태
- 생성 중: 사용자가 입력을 전송했고 시스템이 답변을 생성하는 상태
- 새 결과: 답변 생성은 끝났지만 사용자가 아직 확인하지 않은 상태
- 확인함: 사용자가 패널을 클릭하거나 결과 영역을 확인한 상태

상태 표시는 다음 방식으로 나타낸다.

- 생성 중: 패널 상단의 얇은 진행 바와 `생성 중` 배지
- 새 결과: 패널 테두리 강조, `새 결과` 배지, 사이드바 세션의 점 표시
- 확인함: `새 결과` 배지와 점 표시 제거

## 7. 작업 완료와 미확인 결과

사용자가 Home 패널에서 입력을 전송하면 해당 패널은 `생성 중` 상태가 된다. 생성이 끝나면 `새 결과` 상태가 된다. 이때 사용자가 다른 패널을 보고 있거나 아무 상호작용을 하지 않았더라도, 어떤 세션에 새 결과가 도착했는지 Home 패널과 사이드바에서 모두 알 수 있어야 한다.

사용자가 `새 결과` 상태의 패널을 클릭하거나 결과 영역을 클릭하면 상태는 `확인함`으로 바뀐다.

## 8. 패널 재정렬

사용자는 패널의 그립을 드래그해 Home 안에서 순서를 바꿀 수 있다. 드래그 중에는 다음 피드백이 필요하다.

- 원본 패널은 살짝 흐려진다.
- 커서를 따라 작은 드래그 프리뷰가 나타난다.
- 다른 패널 위에서 놓으면 두 패널의 순서가 바뀐다.

## 9. 프로토타입 필수 시나리오

프로토타입은 다음 흐름을 조작 가능해야 한다.

1. 사용자가 `비즈니스 영어 번역` 세션을 연다.
2. 사용자가 핀 버튼을 눌러 세션을 Home에 고정한다.
3. Home에 해당 세션이 추가되고, 사이드바의 핀 상태도 바뀐다.
4. Home에서 패널에 새 문장을 입력한다.
5. 패널이 `생성 중` 상태가 된다.
6. 답변이 생성되면 `새 결과` 상태가 된다.
7. 사용자가 결과 영역을 클릭하면 `확인함` 상태가 된다.
8. 사용자가 패널 크기를 크게 보거나 작게 접는다.
9. 사용자가 패널을 드래그해 순서를 바꾼다.
10. Home이 가득 찬 상태에서 다른 세션을 고정하려 하면 교체 화면이 나타난다.

## 10. 구현 완료 기준

구현 완료 기준은 다음과 같다.

- Home에 고정된 세션과 사이드바의 핀 상태가 항상 일치한다.
- 고정, 제거, 교체는 토스트 피드백과 실행 취소를 제공한다.
- Home은 4개 제한을 지키고, 5번째 고정 시 교체 플로우를 제공한다.
- 패널은 기본, 크게 보기, 작게 접기 상태를 가진다.
- 패널 입력 후 생성 중, 새 결과, 확인함 상태가 화면에 나타난다.
- 새 결과 상태는 사이드바에서도 확인할 수 있다.
- 드래그 재정렬 중 프리뷰가 보이고, 드롭 후 패널 순서가 바뀐다.
- `pnpm build`가 통과한다.
