# Image Zettelkasten Tag System Plan

## 목적

태그는 카드에 붙는 자유 키워드가 아니라, 사용자가 어떤 조형 요소에 반복적으로 반응하는지 보기 위한 재사용 가능한 조형 어휘 DB다.

따라서 LLM은 매번 임의의 태그를 새로 만드는 것이 아니라, 정해진 카테고리와 기존 태그 DB를 먼저 참고하고, 기존 태그로 설명되지 않을 때만 새 태그를 제안한다.

## 태그 카테고리

태그 카테고리는 조형 분석에 자주 쓰이는 축을 앱에서 쓰기 쉽게 정리한 것이다.

| id | label | 역할 |
| --- | --- | --- |
| subject | 대상 | 이미지 속 관찰 대상. 간판, 타일, 벽면, 계단, 창문 등 |
| form | 형태 | 점, 선, 면, 곡선, 직선, 덩어리 같은 기본 조형 단위 |
| composition | 구성 | 요소들이 조직되는 방식. 반복, 리듬, 정렬, 균형, 중첩 등 |
| color | 색감 | 색상, 명도, 채도, 대비, 그라디언트 등 |
| material | 재질 | 표면과 물성. 유광, 무광, 거친 표면, 유리, 금속 등 |
| space | 공간 | 여백, 깊이감, 압축감, 스케일, 전경과 배경 등 |
| light | 빛 | 그림자, 직사광, 확산광, 역광, 반사광 등 |
| effect | 효과 | 조형 요소가 만드는 감각적 인상. 안정감, 긴장감, 낯섦 등 |

## Firestore 구조

### `tag_categories`

카테고리 정의를 저장한다.

```ts
{
  id: "composition",
  label: "구성",
  description: "요소들이 조직되는 방식",
  examples: ["반복", "리듬", "정렬", "균형", "비대칭", "중첩"]
}
```

### `tags`

재사용 가능한 태그 어휘를 저장한다.

```ts
{
  id: "composition-repeat",
  label: "반복",
  category: "composition",
  aliases: ["반복성", "되풀이"],
  source: "system" | "llm" | "user",
  usageCount: 12,
  createdAt: "...",
  updatedAt: "..."
}
```

### `cards`

카드는 카테고리별 태그 ID 또는 label 배열을 가진다. 현재 프로토타입은 label 기반으로 저장하고, 필요하면 나중에 tag id 기반으로 이관한다.

```ts
{
  id: "...",
  title: "...",
  tags: {
    subject: ["화단"],
    form: ["덩어리"],
    composition: ["분할", "반복"],
    color: ["고채도"],
    material: [],
    space: [],
    light: ["그림자"],
    effect: ["긴장감"]
  }
}
```

## LLM 제안 정책

LLM 입력:

- 현재 카드 이미지 축소본
- 현재 카드 관찰
- 현재 카드 인사이트
- 태그 카테고리 정의
- 태그 DB에 저장된 기존 태그 목록

LLM은 기존 카드 전체 관찰문을 매번 읽지 않는다. 태그 제안의 기준 데이터는 `tags` 컬렉션이다.

LLM 규칙:

- 카테고리와 기존 태그 DB를 먼저 참고한다.
- 같은 의미의 새 표현을 만들지 말고 기존 태그를 재사용한다.
- 기존 태그와 예시로 설명되지 않는 경우에만 새 태그를 만든다.
- 모든 카테고리를 억지로 채우지 않는다.
- 실제로 작동하는 조형 요소가 있는 카테고리에만 태그를 넣는다.
- 새 태그는 짧은 한국어 명사구로 만든다.

응답 구조:

```json
{
  "title": "그림자가 나누는 덩어리",
  "tags": {
    "subject": ["화단"],
    "form": ["덩어리"],
    "composition": ["분할"],
    "color": ["고채도"],
    "material": [],
    "space": [],
    "light": ["그림자"],
    "effect": ["긴장감"]
  },
  "newTags": [
    {
      "category": "composition",
      "label": "비껴난 정렬",
      "reason": "기존 태그로 설명되지 않는 정렬 상태"
    }
  ]
}
```

## UI 정책

제목/태그 단계에서는 카테고리별 입력 영역을 보여준다.

- 제목
- 대상
- 형태
- 구성
- 색감
- 재질
- 공간
- 빛
- 효과

각 카테고리 태그는 칩으로 표시한다. 칩은 hover 시 삭제할 수 있다. 입력칸에서는 쉼표로 태그를 나눌 수 있다.

## 정렬 정책

메인 화면의 정렬 기준은 다음을 포함한다.

- 대상
- 형태
- 구성
- 색감
- 재질
- 공간
- 빛
- 효과
- 수집 시간
- 수집 공간

선택한 카테고리의 태그들이 필터 칩으로 표시되고, 카드는 해당 태그를 가진 경우 중복으로 포함된다.
