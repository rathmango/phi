모래시계 추상화 플로우차트

사용자가 시작 신호를 주면 정해진 총량의 단위가 일정한 처리율로 잔여 상태에서 완료 상태로 전환되고, 그 비율을 통해 시간의 진행과 종료를 보여주는 인터페이스.

UI 상태

  • 대기: 아직 시간 측정이 시작되지 않은 상태
  • 진행: 잔여 단위가 완료 단위로 전환되는 상태
  • 완료: 잔여 단위가 0이 되어 측정이 끝난 상태
  • 초기화: 완료 또는 진행 상태를 다시 시작 가능한 상태로 되돌리는 상태

상태 전환 조건

  • 시작 입력이 발생하면 대기에서 진행으로 전환
  • 시간이 흐르면 처리율만큼 완료 단위가 증가
  • 잔여 단위가 남아 있으면 진행 상태 유지
  • 잔여 단위가 0이면 완료 상태로 전환
