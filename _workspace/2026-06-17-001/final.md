# 태엽식 오르골 분해안 v0.2

```text
태엽식 오르골
└─ 고수준:
   태엽식 오르골은 감긴 태엽이 풀리는 힘으로 실린더를 돌리고,
   실린더에 박힌 핀이 금속 빗살을 차례대로 튕기면서 정해진 음악을 재생한다.

   ├─ 1. 태엽을 감아 재생될 시간을 정한다
   │  ├─ 1-1. 손잡이를 돌려 태엽을 감는다
   │  │  ├─ 손잡이 회전 횟수: n회
   │  │  ├─ 손잡이 회전 각도: θ_handle
   │  │  └─ 손잡이 회전 방향: 1 / -1
   │  ├─ 1-2. 손잡이를 돌린 만큼 태엽 감김 정도가 올라간다
   │  │  ├─ 회전 1회당 감김 증가량: wind_per_turn
   │  │  ├─ 현재 태엽 감김 정도: wind_level, 0~100%
   │  │  └─ 최대 감김 정도: max_wind = 100%
   │  └─ 1-3. 감긴 정도가 오르골이 돌아갈 수 있는 시간으로 남는다
   │     ├─ 감김 1%당 재생 시간: sec_per_wind
   │     ├─ 예상 재생 시간: expected_duration_sec
   │     └─ 남은 재생 시간: remaining_duration_sec

   ├─ 2. 태엽이 풀리면서 실린더가 돌고, 저장된 음의 순서를 읽는다
   │  ├─ 2-1. 감긴 태엽이 풀리며 회전 운동을 만든다
   │  │  ├─ 태엽 풀림 정도: unwind_level
   │  │  ├─ 태엽 풀림 속도: unwind_rate
   │  │  └─ 출력 회전 속도: output_rpm
   │  ├─ 2-2. 회전이 기어를 지나 실린더에 전달된다
   │  │  ├─ 기어비: gear_ratio
   │  │  ├─ 실린더 회전 속도: cylinder_rpm
   │  │  └─ 실린더 회전 방향: 1 / -1
   │  ├─ 2-3. 실린더의 현재 위치가 곡의 진행 위치가 된다
   │  │  ├─ 실린더 현재 각도: cylinder_angle, 0~360도
   │  │  ├─ 실린더 회전 완료 횟수: cylinder_turn_count
   │  │  └─ 곡 진행률: music_progress, 0~100%
   │  └─ 2-4. 실린더 위의 핀이 읽기 위치를 지나가며 다음 음을 정한다
   │     ├─ 핀 개수: pin_count
   │     ├─ 각 핀의 각도 위치: pin_angle
   │     ├─ 각 핀의 가로 위치: pin_x
   │     ├─ 현재 읽기 위치와 핀의 거리: read_distance
   │     └─ 핀 통과 여부: 0 / 1

   ├─ 3. 핀이 금속 빗살을 튕겨 소리를 낸다
   │  ├─ 3-1. 지나간 핀의 위치가 어떤 빗살을 칠지 정한다
   │  │  ├─ 핀 가로 위치: pin_x
   │  │  ├─ 빗살 번호: tine_index
   │  │  └─ 해당 빗살의 음 높이: frequency_hz
   │  ├─ 3-2. 핀이 금속 빗살을 밀고 지나간다
   │  │  ├─ 핀 접촉 여부: contact, 0 / 1
   │  │  ├─ 접촉 깊이: contact_depth_mm
   │  │  ├─ 접촉 시간: contact_duration_sec
   │  │  └─ 튕김 세기: pluck_strength
   │  ├─ 3-3. 밀렸다가 놓인 빗살이 진동한다
   │  │  ├─ 빗살 길이: tine_length_mm
   │  │  ├─ 빗살 두께: tine_thickness_mm
   │  │  ├─ 진동 주파수: vibration_frequency_hz
   │  │  ├─ 진동 세기: amplitude
   │  │  └─ 진동 감쇠율: decay_rate
   │  └─ 3-4. 빗살의 진동이 들을 수 있는 소리로 퍼진다
   │     ├─ 음량: volume_db
   │     ├─ 소리 지속 시간: sound_duration_sec
   │     └─ 현재 울리고 있는 음 개수: active_note_count

   └─ 4. 태엽이 다 풀리면 재생이 끝난다
      ├─ 4-1. 재생되는 동안 태엽 감김 정도가 줄어든다
      │  ├─ 현재 태엽 감김 정도: wind_level
      │  ├─ 감김 감소 속도: wind_decrease_rate
      │  └─ 남은 재생 시간: remaining_duration_sec
      ├─ 4-2. 남은 감김 정도로 계속 재생할 수 있는지 판단한다
      │  ├─ 남은 재생 시간: remaining_duration_sec
      │  ├─ 실린더 회전 속도: cylinder_rpm
      │  └─ 종료 여부: is_finished, 0 / 1
      └─ 4-3. 회전이 멈추고 남은 진동도 사라진다
         ├─ 실린더 회전 속도: cylinder_rpm = 0
         ├─ 현재 울리고 있는 음 개수: active_note_count = 0
         └─ 출력 음량: volume_db ≈ 0
```
