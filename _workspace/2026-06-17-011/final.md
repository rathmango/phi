# Hourglass + Music Box - Prototype v0.1

## 프로토타입 이름

Bow Score Maze

## 한 줄 설명

사용자가 활시위를 당겨 작동 가능량을 정하고, 놓는 순간 에너지 입자가 사전에 정의된 악보 미로를 따라 이동하며 비발디 겨울의 음표와 트리 조명을 함께 완성하는 프로토타입.

## 핵심 구조

| 요소 | 프로토타입에서의 의미 |
|---|---|
| 활시위 당기기 | 작동 가능량 입력 |
| 당긴 거리 | 저장된 에너지 양 |
| 손을 놓기 | 전개 시작 트리거 |
| 악보 미로 | 사전에 정의된 시각/청각 결과의 진행 경로 |
| 미로 위 음표 지점 | 음높이, 음 길이, 조명 위치가 저장된 포인트 |
| 에너지 입자 | 작동 가능량을 소모하며 이동하는 진행 상태 |
| 켜지는 전구 | 시각적 출력 |
| 들리는 음 | 청각적 출력 |
| 크리스마스 트리 완성 | 사전 정의된 결과가 끝까지 전개된 상태 |
| 중간 정지 | 작동 가능량이 부족해 결과가 미완성으로 남은 상태 |

## 음표 데이터

- 곡: Antonio Vivaldi, L'Inverno / Winter, RV 297
- 구간: 첫 악장 solo 트랙 첫 64개 음
- 출처: Mutopia Project MIDI files
- 사용 방식: 음높이와 음 길이는 실제 MIDI 데이터에서 추출하고, 시각적 위치는 크리스마스 트리 형태의 악보 미로에 맞춰 재배치한다.

## 상태 흐름

1. 대기: 악보 미로와 트리 조명은 꺼진 상태로 준비되어 있다.
2. 설정 중: 사용자가 활시위를 아래로 당겨 작동 가능량을 정한다.
3. 전개 중: 손을 놓으면 에너지 입자가 미로를 따라 움직이고, 각 음표 지점에 닿을 때마다 소리와 빛이 발생한다.
4. 미완성: 작동 가능량이 부족하면 중간 지점에서 멈춘다.
5. 완성: 충분히 당기면 모든 음표와 조명이 실행되어 트리 형태가 완성된다.
