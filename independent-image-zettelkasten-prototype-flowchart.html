이미지 제텔카스텐 프로토타입 플로우차트

사용자가 발견한 이미지를 업로드하면, 관찰 가능한 이미지로 정제하고 메타데이터를 수집한 뒤, 사용자가 직접 쓴 관찰 기록을 바탕으로 제목과 주제 태그를 제안하고 카드 템플릿에 배치한다.

자동화 범위

  • 발견 자체는 사용자가 수행한다
  • 프로토타입은 이미지 수집 모듈부터 시작한다
  • 관찰 기록은 사용자가 직접 작성한다
  • 제목과 주제 태그는 시스템이 제안하고 사용자가 확정한다

카드 묶음 원칙

  • 카드는 고정 폴더가 아니라 태그/메타데이터 기준으로 묶인다
  • 사용자가 묶기 기준 필드를 선택한다
  • 한 카드가 여러 값을 가지면 여러 그룹에 중복 포함된다
  • 묶기 기준은 주제 태그, 수집 시간, 수집 공간, 수집 방식 등이 될 수 있다
